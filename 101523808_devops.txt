COMP3104 - DevOps

COMP3104 introduces students to DevOps principles and modern software development practices.

DevOps promotes collaboration between development and operations teams.

The course covers version control, Git, GitHub, branching, continuous integration, and automation.

Git and GitHub

Git tracks changes in project files. GitHub hosts repositories and supports collaboration between developers.

Branching

Branches allow developers to work independently without immediately modifying the shared main branch.

Continuous Integration

Continuous integration uses automated workflows to validate code changes when developers push updates.
